# 1.0 重建计划与能力边界

依据唯一官方参考 `novaemby-plugins-main.zip`，提交 `1d07db1e66b3d870c9b9eb97d43c71a66e56a299`；依据其中 sdk/sdk.go、sdk/capabilities.go、插件开发教程 4.4 / 5 / 6 / 7 节及 hello 0.3.0。

| 官方能力 | 本项目使用方式 | 边界 |
|---|---|---|
| playback.started / paused / progress / stopped | 按播放会话更新记录，合并进度写盘 | 停机事件不补发；未收到停止事件不等于在线 |
| host.item | 片名、年份、剧集、时长补全；计划任务修复历史条目 | 不含海报 URL、图片内容或实时会话列表 |
| page + HTTP + Cookie / CSRF | 手机优先的概况与记录，刷新、分页、筛选、管理 | 不改宿主 DOM / iframe；外层高度由宿主决定 |
| tasks + cancel / progress | 定时清理、手动修复缺失条目信息 | 控制批次和超时，取消可中止 |
| DataDir | 读取旧 history.jsonl，新增记录沿用 JSONL | 保留历史 ID；不从宿主数据库补录历史 |
| TimeZone | 自然日、时段与筛选统一使用宿主时区 | 无效时区回退 UTC 并显示实际使用的时区 |

## 海报结论

旧代码硬编码多条 Emby 图片路径，并把事件字段猜成媒体 ID：任何一环错误都会导致图片失败。官方插件 SDK 仅提供条目信息，不提供图片能力，也不允许插件拿到登录 Token。因此不能承诺通过 SDK 修复所有宿主版本的海报。

新版默认使用完整的内容占位封面；管理员如已确认宿主可用的同源图片路径，可在插件设置填写含 `{id}` 的图片路径模板。浏览器携带同源 Cookie 读取，剧集优先剧集级 ID；失败只尝试下一有效 ID，随后显示占位，不重复猜接口、不拼接 Token、不读取媒体文件。禁止外部域名与协议相对地址。页面在图片失败时提示检查图片地址配置，不把失败解释为无播放数据。

## 全新实现计划

1. 重写事件解析：官方标准字段及用户此前已确认的混淆映射；未知结构拒绝推断并累计诊断数。
2. 重写存储：旧日志读取、损坏尾行恢复、写入事务、进度节流、结束与停机落盘、原子清理，保留旧用户归组兼容。
3. 重写查询：一份快照聚合概况、日趋势、排行、会话；记录筛选与同内容汇总使用一致过滤口径。
4. 重写页面：轻量导航、可读指标、观看时间线、会话卡、排行、移动筛选抽屉、真实加载/失败/无数据状态，亮暗主题。
5. 增加官方 task 修复条目；写操作保留既有内网访问约定并携带 CSRF。
6. 替换旧实现测试，覆盖旧日志迁移、跨设备、迟到事件、夏令时、排序分页、图片配置、请求竞争和写操作。
7. 更新 manifest、版本文档和维护说明。用户同步个人仓库后由 CI 执行 Go 检查与构建；本机不编译、不发布、不留安装包。

执行结果与已验证范围见 README。浏览器 UI 与宿主图片接口需要部署后验收，不能以模拟 DOM 测试代替。

## 本次执行结果

- 已替换旧的全部 Go 实现和旧页面/测试；当前由 domain、storage、query、main、http、media 六个模块构成。
- 新页面包含观看概况、时间线/内容汇总、趋势、排行、会话状态、只读内容弹窗、手动刷新/重试及主题记忆；使用自然文档流，不修改宿主窗口。
- 已实现本地封面读取（图片内容校验、8 MiB 上限、只读普通文件）、管理员配置的同源图片地址和失败占位；SDK 不能保证无本地封面的媒体有海报。
- 已新增 19 项 Go 测试，覆盖旧日志、存储失败、会话关联、节流、清理、自然日/夏令时、分页、路由及封面来源；由 CI 运行，本机未编译。
- 21 项前端行为/接口测试、52 项同步工具测试和 JavaScript 语法检查已通过。
- 未执行真实浏览器或宿主验收；实际图片读取、内嵌外层布局及 Go 构建以用户同步后的 CI 与部署结果为准。当前源码 1.0.0 不等于远端已发布 1.0.0。
